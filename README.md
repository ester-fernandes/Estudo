# ESTUDO

Este repositório contém os projetos que estou desenvolvendo ao longo dos meus estudos na área Dados e Inteligência Artificial. O objetivo é documentar o progresso dos meus aprendizados, aplicar os conceitos adquiridos e compartilhar as soluções que estou criando.

## Estrutura do Repositório

O repositório está organizado em pastas, com cada uma contendo projetos específicos relacionados aos temas que estou estudando. Cada pasta inclui um arquivo **README.md** com detalhes sobre o projeto, as tecnologias utilizadas, como rodar, como contribuir e próximos passos.

## Projetos

Os projetos aqui presentes são focados em:

- **Cauculadora de IMC**
- **Simulador de Compras Online**

Aos poucos, vou adicionando mais projetos e aprimorando os existentes, à medida que vou avançando nos meus estudos.

## Contribuições

Este repositório é um reflexo do meu aprendizado pessoal, e não estou buscando contribuições externas no momento. No entanto, feedbacks construtivos sobre o código e sugestões de melhoria são sempre bem-vindos!

## Objetivo

Meu objetivo é aprimorar minhas habilidades em Dados e Machine Learning, com foco em aplicar os conhecimentos em áreas práticas, como a saúde. Todos os projetos são documentados para facilitar o aprendizado e também para futuras consultas e melhorias.
