# Simulador de Compras Online

## Descrição

Este é um simulador de compras online simples que permite ao usuário adicionar itens ao carrinho, visualizar o carrinho de compras, remover itens e calcular o total da compra. Além disso, o programa oferece a funcionalidade de salvar os dados da compra em um arquivo de texto.

## Tecnologias Utilizadas

- Python
- Bibliotecas: random, time
- Arquivo de dados: .txt

## Funcionalidades

- **Adicionar Itens ao Carrinho**: O usuário pode escolher entre 5 itens disponíveis (Camiseta, Calça, Tênis, Jaqueta, Bermuda), selecionar a quantidade e adicionar ao carrinho.
- **Visualizar Carrinho**: O usuário pode ver todos os itens no carrinho, com a quantidade e o preço de cada um.
- **Remover Itens**: O usuário pode remover itens específicos do carrinho.
- **Calcular Total**: O programa calcula e exibe o total da compra.
- **Salvar Dados da Compra**: O carrinho de compras do cliente é salvo em um arquivo .txt para futura referência.

## Como Rodar o Projeto

1. Faça o download do arquivo do código Python (simulador_compras.py).
2. Certifique-se de que você tem o Python instalado (Python 3.x recomendado).
3. Execute o script no terminal ou IDE de sua preferência.

bash
python simulador_compras.py
