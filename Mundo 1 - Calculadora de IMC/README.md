# Calculadora de IMC

## Descrição do Projeto

A Calculadora de IMC é uma aplicação desenvolvida em Python que permite calcular o Índice de Massa Corporal (IMC) de uma ou mais pessoas. O projeto classifica o resultado em seis categorias baseadas nos padrões estabelecidos (Abaixo do Peso, Peso Normal, Sobrepeso, Obesidade Tipo I, Obesidade Tipo II e Obesidade Tipo III) e fornece mensagens personalizadas que incentivam hábitos saudáveis ou alertam para cuidados médicos. Além disso, é possível armazenar os dados de múltiplas pessoas em uma lista para organização e consulta futura.

## Tecnologias Utilizadas

Python (funções nativas)

## Dependências e Versões Necessárias

Não é necessário instalar dependências externas. A aplicação utiliza apenas as funções nativas do Python.

## Requisitos:

Python 3.x

## Como rodar o projeto

- Certifique-se de que o Python está instalado em seu computador. Você pode verificar executando o seguinte comando no terminal:
python --version

## Baixe o arquivo calculadora_imc.py para o seu computador.

Navegue até o diretório onde o arquivo está localizado usando o terminal.

Execute o seguinte comando:
python calculadora_imc.py
Siga as instruções exibidas no terminal para cadastrar as pessoas e calcular seus IMCs.

## Como rodar os testes

Por enquanto, este projeto não possui testes automatizados. Você pode verificar seu funcionamento manualmente inserindo diferentes dados e conferindo os cálculos e mensagens exibidos.
